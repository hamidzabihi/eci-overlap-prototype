# Phase 1 — SHARC_ECI_GAME overlap + phases extension

If you're here for the ECI2GAME overlap pipeline, start with these:

- `bin/SHARC_ECI_GAME.py` — subclass of `SHARC_ECI` adding `overlap` and
  `phases` requests, writing standard SHARC `QMout` sections `! 6` and `! 7`.
  Zero sharc4 edits.
- `docs/ECI2GAME_status.md` — status of all nine ECI2GAME deliverables,
  with explicit scope boundaries.
- `docs/upstream_pr.md` — the ~30-line sharc4 PR planned for Phase 2.
- `examples/BA_BD_overlap/` — two-step demo (regenerated by
  `scripts/02_setup_demo.sh`; shipped in the tarball but not in git).

Reproduce: `SHARC=/path/to/sharc4 ./scripts/run_all.sh`

The rest of the repo (src/, tests/, docs/gradients_status.md, ...) is the
underlying prototype that validates the overlap formula, phase tracking,
ECI Hamiltonian, and FD gradients. Read `README.md` for that layer.
